# Quiltfen 1.0 TEST
Native Java/Canvas Android 8+ Shakashaka triangle-quilt puzzle.

Tap an editable cell to cycle empty, northwest, northeast, southeast and southwest black half-cell triangles, then empty. Fixed black numbered cells cannot change. Every edge-connected white area must be a filled rectangle or square, either axis-aligned or tilted 45 degrees. A black clue counts neighboring cells containing triangles on its four sides, not the number of dark sides touching it. Twelve distinct 3x3 boards each have three black clues, six editable cells and one unique solution.

Saved quilt palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java geometry cancels shared triangle edges, traces each white boundary and requires exactly four right-angle corners, without production component decoding or bounds tests. It agrees with production quarter-triangle adjacency floodfill and axis/diagonal area bounds on all 15625 states per puzzle. Unique solution, fixed cells, bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, tile taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 114 partial recovered README records and exact Reedtatami cumulative stage found no Shakashaka match. Unlike Blockbloom/Chocona or Squarehaven/Tasquare, cells can hold one of four half-cell triangles: the WHITE complement forms rectangles, including 45-degree ones, and fixed black clues count adjacent triangle cells. There are no room shade quotas, whole-square area sums or global light-connectivity rule. Chocona and Usoone candidates were rejected as existing Blockbloom and Hushgrove. Known Shakashaka genre, not a global invention. Partial recovered corpus, not ALL-local. Rules: https://www.nikoli.co.jp/en/puzzles/shakashaka/ and https://www.puzzle-shakashaka.com/ .
